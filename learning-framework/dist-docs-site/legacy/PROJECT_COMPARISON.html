💡 如何使用这两个项目

场景 1: 学习命令系统

步骤:

  1. 在 learning-framework 中创建简单的命令
  2. 查看 claudecode-project/src/commands/help/ 了解真实实现
  3. 对比差异，理解为什么要那样设计
  4. 改进自己的实现

示例:

# 1. 查看简化版
cat learning-framework/src/commands/hello.ts

# 2. 查看完整版
ls claudecode-project/src/commands/help/
cat claudecode-project/src/commands/help/helpCommand.ts

# 3. 理解差异和改进点

场景 2: 实现 UI 组件

步骤:

  1. 在 learning-framework 中用 Ink 创建基础组件
  2. 研究 claudecode-project/src/components/ 中的组件
  3. 学习高级用法（布局、样式、交互）
  4. 应用到自己的组件中

示例:

# 1. 查看简单组件
cat learning-framework/src/components/App.tsx

# 2. 查看复杂组件
ls claudecode-project/src/components/Input/
cat claudecode-project/src/components/Input/Input.tsx

# 3. 学习并改进

场景 3: 开发工具

步骤:

  1. 在 learning-framework 中实现基础工具
  2. 分析 claudecode-project/src/tools/read/ 等工具
  3. 理解权限、错误处理、结果格式化
  4. 完善自己的工具实现

🎯 学习策略

✅ 推荐做法

  1. 先简后繁

`` learning-framework (简单) → 理解原理 → claudecode-project (复杂) → 深化理解 ``

  1. 对照阅读

``bash # 同时打开两个文件 code learning-framework/src/main.tsx code claudecode-project/src/main.tsx ``

  1. 增量实现

`` Week 1: 100 行代码 → 基础 CLI Week 2: 500 行代码 → 完整功能 Week 3: 1000 行代码 → 可扩展框架 ``

  1. 记录对比

```markdown # 学习笔记

## 我的实现 [简化版代码]

## 原始实现 [生产版代码]

## 差异分析

  • 原始版本考虑了...
  • 我的版本缺少...
  • 需要改进...

```

❌ 避免的做法

  1. 不要直接复制
  • ❌ 复制粘贴代码
  • ✅ 理解后自己写
  1. 不要一开始就看复杂代码
  • ❌ 直接读 785KB 的 main.tsx
  • ✅ 从简化版开始，逐步深入
  1. 不要忽视文档
  • ❌ 只看代码
  • ✅ 代码 + 文档 + 笔记
  1. 不要跳过基础
  • ❌ 直接实现插件系统
  • ✅ 循序渐进，打好基础

📈 难度递进

Level 1: 入门 (Week 1)

  • learning-framework: 100-300 行
  • 参考项目: 看接口定义和简单实现
  • 目标: 能运行基本 CLI

Level 2: 进阶 (Week 2)

  • learning-framework: 500-800 行
  • 参考项目: 看核心模块实现
  • 目标: 实现完整功能模块

Level 3: 高级 (Week 3)

  • learning-framework: 1000+ 行
  • 参考项目: 看架构设计和优化
  • 目标: 构建可扩展框架

    // ...

};

学习要点:

  • 简化版：理解基本概念
  • 生产版：学习工程实践

示例 2: UI 组件

learning-framework (简化):

const App = () => (
  <Box>
    <Text>Hello</Text>
  </Box>
);

claudecode-project (生产):

const App = ({ session, config, theme }) => {
  // 多个 hooks
  const { input, setInput } = useInput();
  const { messages } = useMessages();
  const { theme } = useTheme();
  
  // 复杂的状态管理
  // 性能优化
  // 响应式布局
  // ...
  
  return (
    <ThemeProvider theme={theme}>
      <Layout>
        <MessageList messages={messages} />
        <Input value={input} onChange={setInput} />
      </Layout>
    </ThemeProvider>
  );
};

学习要点:

  • 简化版：掌握 JSX 和 Ink
  • 生产版：学习组件设计和优化
